## 目标

- 注册表新增 `json_fmt`（enabled），自动进入侧栏 / 首页 / 搜索 / 模块管理；
- 左输入右输出：格式化（2/4 空格）、压缩、校验、排序键、复制、清空、载入示例；
- 非法 JSON 给出**行号 + 列号 + 原因**；超过 2 MB 提示，不卡 UI；
- 纯 `dart:convert`，无第三方依赖；着色复用 §7.3 的 JSON 色板（模块内自绘）。
