## 文档体系（本仓库约定）

```
E:\javaclass\posttest\
├─ SPEC\                        # 规格说明书
│  ├─ SPEC.md                   # 永远指向最新版内容
│  └─ SPEC-<日期>-<时间>-<版本>-*.md   # 每次修订的时间戳存档
├─ plans\                       # 计划文档（每个里程碑一份，任务勾选驱动）
│  ├─ ROADMAP-<时间戳>.md        # 本文件
│  └─ PLAN-<时间戳>-M<n>.md
```

## 推进规则

1. 开工一个里程碑前先写 `PLAN-<时间戳>-M<n>.md`（任务清单 + 验收标准，取自 SPEC §9）；
2. 代码只按 SPEC 与当日 PLAN 推进；范围变更先改 SPEC（新时间戳版本）再动代码；
3. 每完成一个任务勾选一项；里程碑验收通过后在 ROADMAP 标 ✅。
