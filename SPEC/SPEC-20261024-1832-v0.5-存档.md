## 1. 项目概述

**ChuYu 万能工具箱**：用 **Dart + Flutter** 编写、可打包**安装到 Windows 电脑**的万能工具箱桌面应用。

- 本体（壳）负责：**单窗口与页面切换**、左侧导航、首页（介绍 + 快速入口）、**全局搜索**、模块注册与加载、全局设置、本地存储；
- 一切具体能力都是**模块**：本期交付第一个模块 **「HTTP 请求测试」**（轻量版 Postman）；
- 同一份模块注册表同时驱动：侧栏导航、首页「全部工具」、全局搜索结果；快速入口为 4 个固定操作（深链接到 HTTP 模块状态）；**新增模块不改核心**；
- 后期持续扩展模块（WebSocket、端口检测、JSON 格式化、时间戳、正则、哈希……）；
- 界面风格：**白色简约**（白色面板 + 浅灰背景 + 细边框 + 单一强调色），中文。

### 1.1 设计原则

1. **模块化至上**：壳零业务逻辑；新能力 = 新模块目录。
2. **轻量（按 Flutter 桌面的真实水平设定）**：安装包 < 40 MB；内存 < 250 MB；冷启动 < 2 s。
3. **数据本地化、纯文本**：JSON 存储，可读可备份可 git。
4. **离线无账号**：除被测目标外不联网、无遥测。
5. **入口高效**：高频操作 ≤ 2 次点击；任意页面可用 `Ctrl K` 搜索直达。

## 3. 技术选型（定稿 Dart + Flutter）

### 3.1 Flutter 做这类工具的优势（定稿理由）

1. **单一代码库多平台**：Windows / macOS / Linux 三桌面一套代码，未来想出移动端也直接复用；
2. **自绘引擎，渲染一致**：不依赖系统 WebView，KV 表格、JSON 语法高亮、可拖拽分栏等工具型 UI 用 Widget 组合即可实现，各系统观感完全一致；
3. **热重载（Hot Reload）**：工具 UI 需要反复打磨，改完界面秒级看到效果，开发效率高；
4. **AOT 编译为原生机器码**：发布版无解释器、性能好、启动快；
5. **生态齐全**：`dio`（HTTP 客户端，拦截器/超时/重定向/表单与流式 Body 全支持）、`path_provider`（系统目录）、`provider`（轻量状态管理）、`msix`/Inno Setup（打包安装）；
6. **Dart 语言简单**：强类型 + 空安全，模块接口清晰，适合长期扩展。

### 3.2 代价（诚实记录）

- 安装包比 WebView 方案大（空项目约 20 MB+），已按 < 40 MB 设定目标；
- 原型是单窗口可交互 HTML，仅作**视觉与交互基准**；Flutter 需用 Widget 按 §7 的量化样式实现，不直接嵌入 HTML。

### 3.3 依赖（pubspec，尽量少）

`dio ^5`、`path_provider ^2`、`provider ^6`；其余需求（JSON 高亮、KV 表格、分栏、全局搜索面板）用 Flutter 自带 Widget 自绘，不引第三方。

## 4. 产品结构（v0.5 定稿）

### 4.1 整体框架

- 窗口默认 **960×640**，可缩放；
- **单窗口 + 页面切换**：同一时刻只显示一个页面，切换不重载、不新开窗口；
- 结构：标题栏 38 px → 左侧导航 216 px + 主内容区 → 状态栏 24 px；
- **左侧导航 = 功能主入口**：品牌区 → 搜索入口 → 首页 → 按分类分组的模块清单（已启用可点，二期置灰标「二期」）→ 底部「模块管理 / 设置」；
- 首页提供**快速入口**与**全局搜索入口**，与侧栏指向同一注册表；
- 窄窗口（< 780 px）时侧栏收缩为 **56 px 图标列**（Flutter 用 Tooltip 显示名称）；
- 标题栏实时显示当前页面名（首页 / HTTP 测试 …）。

### 4.2 首页（介绍 + 快速入口 + 查找）

1. **介绍区**：一句话定位（把常用开发小工具装进一个本地 App）+ 2–3 行说明 + 三条事实（9 个工具 / 1 个已启用 / 数据存本机）；
2. **全局搜索入口**：整行大搜索框，点击或回车打开命令面板，右侧提示 `Ctrl K`；
3. **快速入口（4 个）**：
   - HTTP 请求测试 → 进入 HTTP 模块页；
   - 新建请求 → 进入 HTTP 模块页并聚焦 URL 输入框；
   - 请求历史 → 进入 HTTP 模块页并切到「历史」页签；
   - 请求集合 → 进入 HTTP 模块页并切到「集合」页签；
4. **全部工具**：按「网络测试 / 编码转换 / 开发辅助」三列展示，每项含图标、名称与「可用 / 二期」标记；可用项可点，二期项点击提示「将在二期提供」；
5. **首页不放请求表单等具体功能区**；所有具体操作都在模块页内完成，快速入口只负责跳转；
6. 首页内容保持在 **960×640 一屏内**，不出现需要滚动的默认视图。

### 4.3 模块页（双层侧栏，以 HTTP 测试为例）

- 外层 = 全局导航（固定）；内层 = **模块侧栏**（HTTP 模块为「集合 / 历史」页签，顶部含本地搜索框）；
- 主区：模块头（模块名 + 版本 + 说明 + 帮助/设置/保存）→ 请求构造卡 → 响应卡；
- 支持**深链接状态**：从首页快速入口进入时可指定「集合 / 历史」页签，或直接聚焦 URL；
- HTTP 页布局：请求方法 + URL + 发送按钮；Params / Headers / Body / Auth 页签；响应状态 + 耗时 + 体积 + Body / Headers 页签；Pretty / Raw 视图。

### 4.4 模块管理页

模块清单（图标/名称/描述/分类/版本/启用开关）；「导入本地模块 / 模块市场」二期占位；说明「模块 = 独立目录」的扩展方式。

### 4.5 全局搜索（命令面板，本期范围）

**打开方式**：`Ctrl K`、`/`（焦点不在输入框时）、侧栏「搜索工具」、首页大搜索框。

**数据源**：模块注册表 + 3 个固定快捷操作（新建请求 / 请求历史 / 请求集合）；不索引模块内部数据。

**匹配规则**：
- 字段：名称、分类、一句话说明、关键词；大小写不敏感、子串匹配；
- 本期不做拼音、模糊纠错、全文检索（列入二期）；
- 输入即时过滤，无网络请求。

**结果分组**：快捷入口 → 可用模块 → 二期模块；组内按注册表顺序。

**键盘与操作**：

| 操作 | 行为 |
|---|---|
| `↑` / `↓` | 移动高亮项，列表自动滚动到可见 |
| `Enter` | 打开当前高亮项；无高亮时忽略 |
| `Esc` / 点击遮罩 | 关闭面板，焦点回到触发控件 |
| 点击结果 | 同 Enter |

**结果行为**：
- 可用模块 → 切换到对应模块页；
- 快捷操作 → 切换模块页并进入指定状态（聚焦 URL / 集合页签 / 历史页签）；
- 二期模块 → 保留展示并标「二期」，选中后提示「将在二期提供」；
- 无匹配 → 显示空结果提示，不报错。

**约束**：纯本地；不引第三方搜索库；打开即聚焦输入框；关闭后不保留上次查询。

## 5. 架构与目录结构（Flutter 单体，无 IPC 层）

与 WebView 方案不同，Flutter 是单体应用：模块功能就是普通 Dart 类，**直接方法调用，没有前后端桥接**。

```
lib/
├─ main.dart                     入口（runApp + Provider 装配）
├─ shell/                        壳
│  ├─ app.dart                   MaterialApp + 主题 + 页面切换
│  ├─ nav_sidebar.dart           左侧导航（读注册表渲染，窄窗口收成图标列）
│  ├─ home_page.dart             首页（介绍 / 快速入口 / 全部工具）
│  ├─ quick_actions.dart         快速入口定义（深链接到模块页状态）
│  ├─ search_palette.dart        ★全局搜索（Ctrl K 命令面板）
│  ├─ module_manager_page.dart   模块管理
│  └─ settings_page.dart         设置
├─ core/
│  ├─ module_registry.dart       ★模块注册表（导航 / 首页 / 搜索的唯一数据源）
│  └─ storage.dart               JSON 持久化（path_provider）
└─ modules/
   ├─ toolbox_module.dart        模块抽象接口
   └─ http_test/                 ★本期唯一模块
      ├─ http_test_module.dart   实现 ToolboxModule
      ├─ http_client.dart        dio 封装（超时/重定向/Body 类型）
      ├─ models.dart             请求/响应模型
      ├─ store.dart              集合/历史存取
      └─ ui/                     模块页（模块头+模块侧栏+请求/响应）
```

### 5.1 模块接口

```dart
abstract class ToolboxModule {
  String get id;              // "http_test"
  String get name;            // "HTTP 测试"
  String get category;        // "网络测试"
  String get summary;         // 一句话说明（首页 / 搜索展示）
  List<String> get keywords;  // 搜索关键词，可为空
  String get version;         // "1.0.0"
  bool get enabled;           // 二期模块为 false（导航 / 首页 / 搜索自动处理）
  IconData get icon;
  Widget buildPage(BuildContext context);
}
```

**新增模块 = 建 `modules/<id>/` 目录 + 注册表加一行**；导航、首页总览、搜索结果与模块管理页全部由注册表自动驱动，搜索代码不需要改动。

### 5.2 模块间约束

- 模块之间禁止互相 import，只允许依赖 `core/`；保证未来可拆可删；
- 全局搜索只读取模块元数据（name/category/summary/keywords），**不 import 模块内部实现**。

### 5.3 二期模块候选（本期不做）

WebSocket 测试、端口连通检测、JSON 格式化、Base64 编解码、时间戳转换、正则测试、哈希计算、UUID 生成、接口批量断言、模块市场 / 本地插件加载、深色主题、最近使用与搜索历史、拼音 / 模糊搜索、CLI 模式。

## 6. 首个模块：HTTP 请求测试（本期 MVP，基于 dio）

### 6.1 请求构造

| 项 | 要求 |
|---|---|
| 方法 | GET / POST / PUT / PATCH / DELETE / HEAD / OPTIONS |
| URL | 单行输入；与 Params 表双向同步 |
| Query 参数表 | 启用勾选 + KEY + VALUE + 备注，行增删 |
| 请求头表 | 同上 |
| Body | `none` / `form-data` / `x-www-form-urlencoded` / `raw`（JSON·text·XML·HTML） |
| 其它 | 超时（默认 30 s）；跟随重定向开关（默认开） |
| 快捷键 | `Ctrl Enter` 发送（与发送按钮等价） |

### 6.2 响应展示

- 状态码+短语（2xx 绿/3xx 黄/4xx 橙/5xx 红）、耗时 ms、体积；
- Body：Pretty（JSON 格式化+着色 / XML 缩进）/ Raw；预览（二期）；
- 响应头表；一键复制响应体。

### 6.3 保存与复用

- 集合：新建/重命名/删除；请求存入集合、一键载入重放；
- 历史：自动记录最近 200 次，点击回填，可清空；
- 模块侧栏提供**本地过滤搜索**（按名称 / URL，即时过滤集合与历史列表，不联网）；
- 首页「新建请求 / 请求历史 / 请求集合」三个快速入口可直达上述状态。

### 6.4 明确不做（二期）

环境变量 `{{var}}`、脚本断言、Cookie/Session、导入 Postman 集合、cURL 导入导出、代理设置、自动更新。

```
      └─ history.json     ← 历史（上限 200）
```

请求条目格式：

```json
{ "id":"req_a1b2","name":"用户登录","method":"POST","url":"https://api.example.com/auth/login",
  "params":[{"enabled":true,"key":"from","value":"web","note":""}],
  "headers":[{"enabled":true,"key":"Content-Type","value":"application/json","note":""}],
  "body":{"kind":"raw","rawType":"json","content":"{ ... }"},"timeoutMs":30000 }
```

- 全局搜索与模块内过滤均为**内存过滤**，不额外落盘；
- 不记录搜索历史（二期再做）。

## 10. 风险与对策

| 风险 | 对策 |
|---|---|
| Flutter/VS 工具链未装、下载量大 | M1 专门处理，一次性成本 |
| 安装包偏大 | 目标 < 40 MB；release 用 `--split-debug-info` 等瘦身 |
| 工具型复杂 UI 工作量 | 原型即规格，颜色/字号/间距量化（§7）；能自绘不引包 |
| 超大响应卡顿 | Pretty 上限 2 MB，超出提示切 Raw |
| 单体无隔离 | 模块禁止互相 import（§5.2），保留拆分可能 |
| 入口增多后行为不一致 | 侧栏 / 首页 / 搜索统一由注册表生成；快捷操作集中在 `quick_actions.dart` |
| HTML 与 Flutter 渲染差异 | 以 §7 的 token 为准，允许 ±1 px 微调，不改变层级与主色 |
